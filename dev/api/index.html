API Reference#

Item parameter calibration for item response theory.

Each object is documented at its public import path. The item bank, irtlib.ItemBank, and its model, irtlib.IrtModel, come from irtlib; everything else comes from its module:

  • the item response functions and the quantities derived from them, from irtlib.irt;

  • the quadrature grid, the ability priors and the posterior over the grid, from irtlib.quadrature;

  • the calibrators, from irtlib.mml, irtlib.cml and irtlib.jml, with the result they share and the checks of a response matrix in irtlib.calibration;

  • ability estimation, from irtlib.ability;

  • item fit and model comparison, from irtlib.fit and irtlib.comparison;

  • responses drawn from the model, from irtlib.drawing;

  • the array types of the signatures, from irtlib.typing.
