irtlib - Item Response Theory for Python#

irtlib implements item response theory for the unidimensional dichotomous logistic models, 1PL to 4PL: the item response functions and the quantities derived from them, item calibration, ability estimation, item fit and model comparison. It runs on NumPy and SciPy alone.

irtlib has no release yet

Install it from source, as the README shows. Its interface may change before the first release.

Calibrate an item bank#

Researchers estimate the items’ parameters, with their standard errors, from the responses of a sample of examinees: by Marginal Maximum Likelihood for the 1PL to 4PL, which takes missing responses, by Conditional Maximum Likelihood for the Rasch model, or by Joint Maximum Likelihood for the Rasch model and the 2PL. Item Fit and Model Comparison then check the calibration.

Score examinees#

Researchers estimate each examinee’s ability, with its standard error, from responses to items of known parameters: by Maximum Likelihood, Maximum A Posteriori, Expected A Posteriori or Weighted Likelihood.

Build on irtlib#

Package authors use irtlib’s item bank (irtlib.ItemBank), item response functions (irtlib.irt) and quadrature grid (irtlib.quadrature). catsim, which computes and evaluates computerized adaptive tests, is built on them.
